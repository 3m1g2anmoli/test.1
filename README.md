# Rock Paper Scissors

A simple command-line Rock Paper Scissors game written in C++.

## Build

```bash
g++ -std=c++17 -Wall -Wextra -pedantic rock_paper_scissors.cpp -o rock_paper_scissors
```

## Run

```bash
./rock_paper_scissors
```

Choose one of the following options:

- `1` for Rock
- `2` for Paper
- `3` for Scissors
- `0` to quit

The game keeps track of the scores until you choose to quit.
